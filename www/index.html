Balanceador & Calculadora de Pesos Atómicos

Escribe una ecuación química. El sistema arma variables por compuesto, plantea una ecuación por cada elemento, resuelve el sistema lineal y muestra el peso molecular de cada sustancia paso a paso.

Para una ecuación usa -> o = como flecha y + entre compuestos, ej. KMnO4 + HCl -> KCl + MnCl2 + H2O + Cl2. Para un elemento o compuesto suelto escríbelo directo, ej. Fe2(SO4)3 o Na (también puedes separar varios con +).
Pesos atómicos redondeados a la unidad (decimal >5 sube, ≤5 se recorta). Uso educativo.
